# Visualizador-3D / 3D Web Viewer

## Description
A web application that allows users to load and explore 3D models in the browser.

## Features
- Load 3D models (.glb, .obj)
- Camera controls (zoom, rotate)
- Basic lighting

## Proposed Tech Stack
- JavaScript
- Three.js
